# Penetration Testing Automation Scripts

A collection of Python scripts designed to automate simple, repetitive tasks commonly performed during penetration testing and Vulnerability Assessment and Penetration Testing (VAPT).

## Purpose

The purpose of this repository is to build practical security scripting skills and develop small utilities that assist with reconnaissance, scan analysis, reporting, and other penetration testing activities.

## Language and Libraries

- **Language:** Python
- **Libraries:** Python standard library modules, depending on the script.

## Scope

This repository focuses on small, practical automation utilities rather than building a complete penetration testing framework.

## Disclaimer

Use these scripts only on systems and networks you own or have explicit authorization to test. The author is not responsible for unauthorized or improper use.
